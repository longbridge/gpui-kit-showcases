# Astrolith

Astrolith is a local-first desktop editor for Astro content collections. Open an existing project, browse its entries, and edit Markdown, MDX, or YAML in the project's own files.

## Writing

The Writing workspace centers the draft and keeps collections and entry details close at hand. The Details panel builds a frontmatter form from the collection schema. Focus and Typewriter modes support longer writing sessions. Autosave detects conflicting disk edits, and recovery snapshots keep unsaved work available after an interruption.

## Build

Switch to Build to browse the project tree and edit source files in tabs. The integrated terminal runs project commands, and installed language servers provide completions, diagnostics, and navigation.

## Preview

Read the current Markdown or MDX draft in the rendered view. Open the Astro site in your browser to see the content with the project's own layout and styles. The active document and unsaved edits stay in place when switching modes.

Astrolith is available as a Linux alpha and is built with Rust and GPUI Kit.
