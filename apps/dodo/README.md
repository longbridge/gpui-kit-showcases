# Dodo

Dodo is a native desktop developer toolbox built with GPUI Kit.

It brings commonly used development workflows into a single fast desktop application, reducing the need to switch between separate tools for APIs, containers, databases, diagrams, and developer utilities.

## Developer Tools

Dodo provides an integrated workspace for:

* Exploring and testing HTTP APIs
* Managing containers, images, volumes, and networks
* Working with databases such as PostgreSQL, MySQL, MariaDB, Redis, and SQLite
* Creating technical diagrams and visual workflows
* Running common developer utilities and formatters
* Managing multiple development workflows from one desktop interface

## API Explorer

Build and organize HTTP requests, inspect responses, work with structured payloads, and use scripting tools without leaving Dodo.

## Containers

Inspect and manage containers and related resources from a native desktop interface, including container status, resource information, ports, images, volumes, and networks.

## Database Manager

Connect to development databases, explore data, execute queries, and inspect results alongside the rest of your development workflow.

## Dodo Flow

Create diagrams and technical visualizations directly inside Dodo.

Dodo Flow supports structured diagramming workflows for explaining systems, processes, architectures, and other technical concepts.

## Integrated Input Tools

Dodo also includes multilingual input tooling designed to make language switching and Vietnamese Telex input available alongside everyday development work.

## Built for Desktop Development

Dodo is designed as a native desktop application with a unified interface for tools developers frequently use throughout the day.
