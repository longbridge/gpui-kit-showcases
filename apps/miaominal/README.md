# Miaominal

Miaominal is a desktop SSH workspace for remote development and server operations. It brings terminal sessions, SFTP file transfers, port forwarding, host management, and secure credential storage into one focused workspace.

## Key Features

- Manage SSH hosts, authentication methods, tags, groups, proxies, and startup commands.
- Work with multiple terminal tabs, split panes, scrollback search, and detached windows.
- Browse remote files and perform SFTP uploads, downloads, folder operations, and transfers.
- Configure local and remote port forwarding for saved SSH hosts.
- Monitor remote CPU, memory, disk, network, and load metrics.
- Store credentials securely using the system keyring or an encrypted local vault.
- Synchronize encrypted configuration through GitHub Gist or WebDAV.
- Export saved hosts for use with external OpenSSH clients.
- Use the Session Agent to inspect files, run tasks, and manage remote development workflows.

Miaominal is designed for developers who regularly work across multiple servers and want their connections, terminals, files, and operational tools in one consistent desktop application.
