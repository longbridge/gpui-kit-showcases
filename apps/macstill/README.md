# Macstill

Macstill is a macOS-inspired desktop environment for Linux, built with Rust, GPUI Kit, and Hyprland. It brings application launching, file browsing, window organization, and system controls into a unified desktop experience.

## A connected desktop

The desktop shell combines a Dock for pinned and running applications with Launchpad for browsing and opening apps. Custom application icons let users personalize the desktop.

## Files and windows

Finder provides file browsing with integrated search. Mission Control presents workspaces and windows in an overview, while Stage Manager offers another way to organize and switch between windows.

## System tools

Macstill includes system settings and hardware information interfaces, alongside screenshot tools and AirDrop integration. These components are being developed as part of the desktop environment.

## Development status

Macstill is under active development and currently targets Linux with Hyprland. Some system information and screenshot functionality is incomplete, settings are being refined, and the password manager currently provides a UI only.
