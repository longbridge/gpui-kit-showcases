# RTX-FG-Manager

RTX-FG-Manager keeps frame generation mods, presets and graphics runtimes together for each game. Select a title in the game library to see its executable folders, current patch and available alternatives.

Player recommendations show which patch, settings and runtime versions someone used for the same game. You can compare their changes with the defaults and choose which parts to apply. When you remove a managed patch, the app restores the original files it backed up.

The desktop interface is built with Rust and GPUI Kit. The portable Windows edition supports Windows 10 and 11. The experimental Linux AppImage manages Windows games running under Wine or Proton.
