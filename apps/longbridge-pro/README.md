# A native trading desktop

Longbridge Pro is the trading desktop that GPUI Kit was originally built for. It brings real-time quotes, charts and dense market data into a desktop application available on macOS, Windows and Linux.

## Market information in one workspace

- Follow real-time quotes.
- Explore market charts.
- Work with dense market data in a native desktop interface.

[Visit the Longbridge Pro website](https://longbridge.com/desktop).
