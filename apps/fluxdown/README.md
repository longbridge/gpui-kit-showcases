# FluxDown

FluxDown is a free, open-source, multi-protocol download manager — a modern alternative to IDM. A single Rust download engine powers a native GPUI Kit desktop client on Windows, macOS and Linux.

## Features

- **Accelerated downloads** — dynamic multi-segment HTTP/HTTPS and FTP downloading with automatic segment splitting, resume and retry.
- **BitTorrent and magnet links** — choose files before downloading, with seeding control.
- **Streaming media** — HLS and DASH streams with quality selection.
- **Queues and groups** — schedule, prioritize and batch-manage tasks with smart sorting and status folders that embed your categories.
- **RSS auto-download** — subscribe to feeds and let filters create downloads unattended.
- **Browser integration** — capture downloads from the browser extension or userscript straight into the desktop app.
- **Themes and icon packs** — customizable themes and file icon packs.
- **Remote and headless use** — run the same engine on a NAS or server and manage it from a web UI.

No ads, no account required, and telemetry limited to anonymous install/active counters that can be turned off.

Learn more at https://fluxdown.zerx.dev or browse the source at https://github.com/zerx-lab/FluxDown.
