# Reviu

Reviu is a native Git client for macOS, Windows, and Linux, built with Rust and GPUI. It brings local changes, AI-assisted development, and GitHub reviews into a keyboard-driven desktop workflow.

## Review local changes

Read and edit diffs in inline or split views, stage individual hunks, and resolve merge conflicts. A command palette provides access to branches, commits, rebases, stashes, and cherry-picks. An integrated terminal stays alongside the selected repository.

## Give feedback to your agent

The sidebar can run Claude or Codex. Add comments to specific lines in a local diff and send that feedback back to the agent for another iteration. Local Git and agent-review features are available without a Reviu account.

## Bring GitHub reviews into the app

Reviu Pro adds a GitHub workspace with notifications, repositories, and filtered pull request lists. Reviewers can inspect changes, discuss lines, follow checks, approve or request changes, and merge from the desktop.

The desktop client is source-available under the Functional Source License; its releases transition to Apache-2.0 after two years. The Pro integration backend is closed-source.
