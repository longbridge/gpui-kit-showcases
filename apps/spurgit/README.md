# Spur

Spur is a native Git client for Windows and macOS, with macOS support currently experimental. It discovers repositories and linked worktrees under your chosen folders and keeps their status visible as you work. On Windows, it also handles repositories inside WSL.

## Work across repositories

Monitor local changes and branch status across multiple checkouts. Fetch remotes together and pull repositories that can safely fast-forward. Repository tabs and a command palette help you move between projects.

## Everyday Git work

Explore commit history with a branch graph and per-file diffs. Stage files or individual hunks, commit changes, manage branches and tags, inspect stashes, and resolve conflicts. An operation log records Git output, and an undo mechanism retains backups for destructive operations.

Spur is in early development. It includes light and dark themes and remappable keyboard shortcuts.
