# So Novel

So Novel is a native desktop application for discovering, collecting, and reading web novels from multiple online book sources. It brings source aggregation, concurrent chapter retrieval, a local library, an in-app reader, and multi-format export together in a single window.

## Highlights

- **Multi-source search**: query by title or author across many book sources at once, compare result quality, preview covers, inspect details, and choose chapter ranges before starting a task.
- **Concurrent download tasks**: retrieval runs in parallel with retries, live progress, cancellation, and cover embedding. Tasks persist between launches.
- **Local library**: scan an existing collection or import books manually. Covers, metadata, reading progress, favorites, and missing-file states are tracked automatically.
- **Built-in reader**: open TXT and EPUB books with scrolling or paginated layouts, a chapter outline, bookmarks, in-book search, and adjustable typography, spacing, page width, theme, and full-screen mode.
- **Book source management**: switch rule sets, import JSON definitions, enable or disable sources, and test connectivity.
- **Export and localization**: produce EPUB, TXT with selectable encodings, HTML zip bundles, or PDF with embedded CJK fonts. The interface is available in Simplified Chinese, Traditional Chinese, and English, with dozens of themes.

## Typical workflows

1. Search for a title or author and compare matches from every enabled source.
2. Open a result to review its description and chapter list, then start a download for all or selected chapters.
3. Follow progress on the task page and cancel or inspect tasks as needed.
4. Scan the download folder to populate the library, or import individual files.
5. Continue from the last reading position, add bookmarks, or export a copy in another format.

## Use cases

- Readers who follow serialized fiction across several sites and want one search entry point.
- People building a personal offline library with covers, metadata, and reading history.
- Users who need to convert between common ebook formats for different devices.
- Anyone who prefers a fast native desktop interface over a browser full of tabs.
