# LumilioCL

LumilioCL is a native Minecraft launcher written in Rust with GPUI and GPUI Kit. There is no Electron or WebView: the interface, the downloads, the world map and the 3D schematic preview are all compiled code. It runs on macOS (Apple silicon), Windows 10 and 11 (x64) and Linux (x64), with the interface in English and Simplified Chinese.

## Game library

Create Vanilla, Fabric or Quilt games, or bring games over from MultiMC, Prism and .minecraft without changing the original files. Modrinth `.mrpack`, CurseForge and MultiMC / Prism modpacks import directly. Favorites, collections and search keep a large library in order, and snapshots, full backups and modpack export protect each game.

## Discover

Browse mods, resource packs, shaders and modpacks from Modrinth and CurseForge inside the launcher. Filter by game version and loader, and install straight into the current game; downloads and their progress appear in Activity.

## World map

Draw the surface of a world from its saved Region files, or predict structure locations from the seed alone. Structure, chunk and Region layers can be turned on and off, coordinates can be copied, and waypoints are shared in a format that Xaero's Minimap understands.

## Litematica schematics

Open Litematica schematics, read the material list and export it as CSV, or look at the build in 3D with the game's own textures, either orbiting it or flying through it in first person. The schematic studio can also replace blocks, convert schematics between game versions, find duplicate files and restore earlier copies.

## Help when the game crashes

When a game crashes, the launcher reads its logs and crash report, states the probable cause in one sentence and suggests a fix, with the technical details one step further. The full analysis can be copied with personal details removed.

## Made for every kind of player

- Java is detected automatically, and the recommended version can be downloaded.
- Microsoft, offline and third-party accounts, with skin previews including capes and elytra.
- Download sources, mirror priority, custom download URL rules and parallel downloads, with the official source kept as a fallback.
- Light and dark themes, fonts, interface scale and custom themes.
- Built-in plugins, including Discord status.

LumilioCL is open source under AGPL-3.0-only.
